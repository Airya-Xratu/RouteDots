# Roadmap

| #   | Milestone                   | Status              |
| --- | --------------------------- | ------------------- |
| 1   | Foundation & Tooling        | ✅ done (PR #1, #2) |
| 2   | Geo Engine & Dot Texture    | ⏳ planned          |
| 3   | Globe Renderer              | ⏳ planned          |
| 4   | Curved Route Arcs           | ⏳ planned          |
| 5   | Plane Animation & Fallback  | ⏳ planned          |
| 6   | Public API, Showcase & Docs | ⏳ planned          |
