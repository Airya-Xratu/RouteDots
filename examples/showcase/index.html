Why RouteDots

      

        The flight-route visual your hero deserves — no API keys, no map tiles, no flat map.
      

      

        
🌍 A real sphere

        

          The globe is spherical, not flat. When your destination is off screen, the camera pans
          across the surface to frame the route.
        

      

      

        
➰ Curved arcs

        

          Routes follow lifted great circles — the classic airline-map bulge — never straight lines.
        

      

      

        
⇄ Outbound ≠ return

        
Round trips draw two arcs with different lifts, so there and back never overlap.

      

      

        
✈️ A plane on repeat

        

          A small airliner flies the outbound arc on a repeating interval, oriented along the track.
        

      

      

        
🎛 Yours to style

        

          One palette for every colour, plus the plane icon, the city ripple, the dash pattern and
          each leg's curve angle — set them up front or restyle a live scene with
          setOptions().
        

      

      

        
🌐 Globe or flat, 3D either way

        

          Render the sphere or an equirectangular map — and give the flat one a real 3D camera:
          perspective, drag-to-orbit, zoom and depth-layered routes.
        

      

      

        
🪶 Feathers light

        

          One dependency (three.js), a bundled 110m land mask, ~9 kB gz of RouteDots core, and a
          flat 2D fallback when WebGL is unavailable.
        

      

    


    

      
Drop it into your hero

      
One element, one call. Works with any stack — here is the whole integration:

      
<div id="hero-globe"></div>
<script type="module">
  import { RouteDots } from 'routedots'; // or the IIFE: <script src="routedots.browser.global.js">

  const rd = new RouteDots(document.getElementById('hero-globe'), {
    theme: 'light',
    autoRotate: { enabled: true, speed: 0.4 },
  });

  // From your flight form:
  document.getElementById('search').addEventListener('click', () => {
    rd.setRoute('LHR', 'DXB', { roundTrip: true });
  });

  // Make it yours — every value applies live:
  rd.setOptions({
    colors: { outbound: '#0ea5e9', plane: '#0ea5e9' },  // or rd.setColors({...})
    route: {
      outbound: { angle: 30, dash: { length: 0.04, gap: 0.02, speed: 2, width: 2.4 } },
      return: { angle: -30, lift: 0.28 },
    },
    cities: { periodMs: 1200, ripple: { size: 0.02, width: 0.004, grow: 4 } },
    plane: { icon: 'jet', size: 0.03 },
    camera3d: { enabled: true, tilt: 40, yaw: -12, depth: 90, interactive: true },
  });
</script>
